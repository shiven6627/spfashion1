# SP Fashion MERN Project — Responsive Update

This copy adds a shared responsive stylesheet at `frontend/src/responsive.css`, imported from `frontend/src/main.jsx`. It includes layout adjustments for tablet and mobile widths while leaving application logic unchanged.

## Setup

1. Copy `backend/.env.example` to `backend/.env` and fill in your own backend credentials.
2. Copy `frontend/.env.example` to `frontend/.env` and fill in your own frontend values.
3. Install dependencies in both folders:
   - `cd backend && npm install`
   - `cd frontend && npm install`
4. Run each app using the scripts in its respective `package.json`.

For security, real `.env` files and `node_modules` are not included in this archive.
